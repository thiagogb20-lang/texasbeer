# Conselho IA

PWA em que várias IAs gratuitas debatem uma ideia e entregam um resumo pronto para o Claude.
As chaves ficam só no navegador de quem usa; este repositório não guarda nenhuma.

Ideias de referência, sem código copiado: [llm-council](https://github.com/karpathy/llm-council) e [free-claude-code](https://github.com/Alishahryar1/free-claude-code).
